## C. Visual improvements

**Navigation:** at 1440 × 1000, the context bar measures **59 px**, down from **93 px** (34 px shorter). Main navigation is 8 px shorter. Explicit, keyboard-accessible native Switch workspace/profile buttons remain: selection alone does not unexpectedly navigate, switching still uses CSRF-protected POST, and no JavaScript is required. Secondary workspace management moved into the account menu, available to existing authorized members. The role badge remains; viewer guidance remains available. Empty profile selection reads “Workspace-wide care,” not an individual recipient.

**Settings/account:** account dropdown distinguishes My account, Preferences, Workspace settings, Guided setup, Product tour and Sign out. Shared navigation on relevant settings pages identifies the current section. Account & security retains email/password/session controls, with bounded input widths and balanced cards. On narrow screens the settings navigation scrolls horizontally rather than stacking eight tall rows; native keyboard focus can reach every link.

**Page shell:** calendar and normal feature pages retain the shared header. The account page previously lacked workspace context because auth routes bypass workspace resolution; verified account pages now receive authorized context without changing their independent security gate. Communication focus mode intentionally hides the shell and remains unchanged.

**Dashboard:** slimmer navigation and tighter spacing bring real statistics from document Y **516 px to 474 px** on the fictional desktop preview. Setup remains compact and dismissible with existing progress/resume semantics. All four metrics, checklist and quick actions remain driven by existing services.

**Routines:** Library/Schedule/History current states, consistent secondary-navigation spacing, compact filters, naturally wrapping titles and footer action alignment. Existing completion, scheduling and management controls remain.

**Calendar:** period navigation is a clear action group; Today retains type/timezone/view/visibility. Grid week spacing, empty-date typography and wrapping improve readability. Event labels retain textual kinds/statuses. Very long grid titles use a three-line visual clamp and reveal fully on focus; full accessible text and detail links remain. No recurrence or timezone calculations changed. Existing mobile agenda remains.

**Care team:** zero/one/two-task views place the real task list beside helpful existing actions (my responsibilities, upcoming tasks, handoffs, activity); larger lists use the existing responsive grid. No invented activity/summary counts or additional dashboard queries. Create/share links retain capability checks. Empty task, handoff, history and activity pagination bars no longer render.

**Shared controls:** native inputs and buttons retain at least 44 px height, readable focus and disabled states. Reduced-motion/personal accessibility settings remain. No custom dropdown dependency or permanent sidebar.
